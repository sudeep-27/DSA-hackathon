How the algorithms work

    
    
      
  • Welsh-Powell (greedy): sort courses by number of conflicts. Fill Slot 1 by walking down the list, taking every course that has no conflict with the slot while halls are free; repeat for Slot 2, 3, …
    • 
      
  • DSatur (greedy): always schedule next the course whose conflicting courses already use the most different slots, and put it in the lowest slot with no conflict and a free hall.
    • 
      
  • Branch & Bound (exact): starts from the best greedy answer and searches only for timetables with fewer slots. It stops at the lower bound (largest clique found, or ⌈N/R⌉), never opens more than one new slot per step, and cuts branches that already need too many slots or don't have enough free halls left. Running time is exponential in the worst case, so a time limit applies. A result that hit the limit is marked not proven optimal.
    • 
      
  • Proven optimal: a greedy result counts as proven when it equals the lower bound or the exact optimum.
